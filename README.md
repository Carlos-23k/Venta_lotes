# Sistema de Venta de Lotes 

**Curso:** Fundamentos de Programación  

## 1. Objetivo del proyecto
Construir un sistema de consola funcional para gestionar lotes y registrar ventas de la empresa Terrenos del Norte S.A.C. . El objetivo es aplicar la programación modular, dividiendo el código en archivos independientes con responsabilidades únicas para facilitar el mantenimiento y el trabajo colaborativo.
